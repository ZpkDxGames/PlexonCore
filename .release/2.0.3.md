# PlexonCore 2.0.3

PlexonCore 2.0.3 adds the shared opt-in player activity watch runtime required by Core-native teleport warmups and other short-lived player activity policies.

## Added

- `PlayerWatchService` registered through Bukkit's ServicesManager.
- Opt-in movement, damage, quit, world-change and death watches.
- Shared listener ownership in Core with O(1) early exit when a player has no active watches.
- MONITOR-stage movement and final non-cancelled damage facts.
- Auto-close watch handles and runtime watch statistics.

## Compatibility

- Core API version remains 2.0.
- Existing 2.0.x consumers remain source/binary compatible.
- Paper 26.2 / Java 25.
