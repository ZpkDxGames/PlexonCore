# PlexonCore 2.0.4

PlexonCore 2.0.4 is a lifecycle-safety patch for the ecosystem certification wave. It prevents stale module registrations and old plugin instances from surviving disable/hot-enable transitions.

## Fixed

- Remove Core module descriptors owned by a plugin as soon as that exact plugin instance disables.
- Prevent disabled plugin instances from blocking a fresh instance from reclaiming the same module ID.
- Add ownership-aware module state updates so late asynchronous callbacks from an old instance cannot mark a replacement module `READY` or otherwise mutate its health.
- Prevent API-incompatible duplicate registrations from overwriting an already active module ID.
- Exclude disabled Plexon plugins from the Legacy/Standalone inventory.
- Clear module ownership state during PlexonCore shutdown.

## Tests

Added regression coverage for:

- disabled-owner replacement;
- exact-instance unregister semantics;
- late state-update races across replacement instances;
- incompatible duplicate module IDs.

## Compatibility

- PlexonCore plugin version: 2.0.4
- Core API: 2.0
- API 1.0 compatibility bridge remains enabled.
- Paper: 26.2
- Java: 25

No gameplay behavior or public package names are intentionally changed. The existing non-owner-aware `updateState(id, state, detail)` method remains available for binary/source compatibility; first-party modules should migrate to the owner-aware overload when state completion may be asynchronous.
