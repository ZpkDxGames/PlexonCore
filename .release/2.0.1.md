# PlexonCore 2.0.1

PlexonCore 2.0.1 is a focused Runtime API correctness and provenance-migration patch.

## Runtime outcome fixes

- Captures immutable block facts and event-time origin before provenance cleanup.
- Defers module block subscribers to the final `MONITOR` stage.
- Suppresses callbacks for finally cancelled `BlockBreakEvent`s.
- Exposes final `dropItems` in `CoreBlockBreakContext` while retaining the original Core 2.0.0 constructor signature.

## Provenance migration

- Adds the idempotent batch block-origin import API introduced for Core-backed module migrations.
- Imported positions persist with conflict-safe semantics and remain fail-closed while persistence is unavailable.

## Release pipeline

Build and release workflows derive artifact names from Maven and enforce tag/project-version parity.
