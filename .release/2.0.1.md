# PlexonCore 2.0.1

PlexonCore 2.0.1 is a focused runtime correctness patch for Core 2 block-break consumers.

## Fixed

- Captures immutable block facts and origin at `HIGHEST`, before Core provenance cleanup consumes the source position.
- Defers module subscriber dispatch to the final `MONITOR` stage.
- Suppresses subscriber callbacks when the final `BlockBreakEvent` is cancelled.
- Preserves event-time `PLAYER_PLACED`/`NATURAL`/`UNKNOWN` origin while final cancellation is evaluated.
- Exposes the final `dropItems` outcome in `CoreBlockBreakContext`, allowing consumers to preserve drop/tool eligibility semantics after other plugins have modified the event.
- Retains the Core 2.0.0 context constructor signature for existing compiled consumers.
- Prevents Core-backed modules such as PlexonKeys from rewarding or progressing a break that protection plugins cancel after the earlier acquisition stage.

## Release pipeline

The build and tag-driven release workflows now derive the project version and artifact path from Maven instead of hardcoding `2.0.0`.

## Compatibility

This is an additive/behavioral patch for the PlexonCore 2.0 runtime API. Existing API 2 consumers do not need source changes.
