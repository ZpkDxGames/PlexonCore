# PlexonCore 2.0.0

PlexonCore 2.0.0 establishes the Core-first shared runtime backbone for the PlexonCraft ecosystem while preserving the public infrastructure introduced in 1.0.

## Highlights

- Core API 2.0 with a temporary API 1.0 compatibility bridge for incremental module migration.
- Centralized high-frequency block-break event gateway.
- Immutable shared event contexts that do not retain live Bukkit/Paper objects beyond synchronous acquisition.
- Precompiled material routing so events are dispatched only to interested modules.
- Lazy item/PDC identity extraction by requested namespace.
- Core-owned block-origin tracking for natural, player-placed and unknown state.
- SQLite/WAL-backed origin persistence with chunk-local caches and fail-closed UNKNOWN behavior while persisted state is unresolved.
- Bounded compute and IO executor lanes with queue/rejection diagnostics.
- Atomic batch/coalescing primitive for high-frequency progression workloads.
- Runtime counters and rolling P50/P95/P99 timings for gateway, context and dispatch stages.
- `/plexon perf` diagnostics.
- Hot-path allocation reductions including monotonic event IDs and ordinal-indexed material route plans.

## Compatibility

Existing Core 1.0 services remain available, including configuration, text rendering, GUI/session helpers, item snapshots, integration lookup, module registry, SQLite helpers and diagnostics. Gameplay modules remain independently versioned and are not embedded into Core.

PlexonTools is the recommended first Core 2 migration target after deployment.

## Platform

- Paper 26.2
- Java 25
- Maven build

## Verification

The release source is built with `mvn -B -ntp clean verify`. CI validates the final JAR structure and publishes a SHA-256 checksum alongside the release artifact.

Automated coverage includes API compatibility, routing, batching, origin coordinate packing, runtime metrics, event utilities, text policy and bounded scheduler backpressure.

## Upgrade notes

Back up the existing PlexonCore data directory before replacing 1.0.0. Existing Plexon gameplay plugins may remain installed and continue operating through compatibility/legacy discovery while each repository is migrated separately.

No third-party gameplay system is decommissioned by this release.
