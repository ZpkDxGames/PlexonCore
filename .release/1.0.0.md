# PlexonCore 1.0.0

Initial stable foundation release for the PlexonCraft plugin ecosystem.

### Included

- Plexon module registry and legacy Plexon plugin discovery
- Core API versioning (`1.0`) and compatibility ranges
- Safe atomic configuration loading, validation, migrations and backups
- SAFE / LEGACY / MINIMESSAGE text rendering policy
- Controlled PlaceholderAPI rendering
- Protected GUI builders and per-player sessions
- Full Paper ItemStack snapshots, exact matching and SHA-256 fingerprints
- Per-module SQLite/WAL utilities and bounded asynchronous writer queues
- Shared integration registry
- Lifecycle-aware bounded scheduler helpers
- Health snapshots and `/plexon` diagnostics GUI/subcommands
- Maven Java 25 build, CI, tag-driven release workflow and SHA-256 checksum

Existing Plexon gameplay plugins remain standalone until explicitly migrated. PlexonCore 1.0.0 does not rewrite their configuration, databases, commands, events or player data.
