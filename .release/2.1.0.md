# PlexonCore 2.1.0

PlexonCore 2.1.0 is the full stable hardening release for the shared runtime foundation used by the PlexonCraft plugin family. It preserves the established API 2.0 surface and API 1.0 bridge while adding the API 2.1 contract and tightening lifecycle, persistence, scheduling, GUI, integration, and diagnostics behavior.

## Highlights

- Owner-scoped lifecycle cleanup for event subscriptions, player watches, GUI sessions, and scheduled work.
- Contributor-based Core health aggregation with clearer degraded/failed state reporting.
- Hardened scheduler observability, cancellation, repeating-task ownership, shutdown behavior, and failure recovery.
- Block-origin persistence with coalesced last-write-wins buffering, pressure flushes, retry visibility, and bounded shutdown.
- Lifecycle-owned SQLite writers with transaction rollback/recovery and future-schema refusal.
- Capability-aware integration discovery and lifecycle refresh.
- GUI generation/session validation with stale-session rejection and permission-safe deferred actions.
- Cached PlaceholderAPI adapter lifecycle to remove reflective discovery from rendering hot paths.
- Deterministic item identity and fingerprint behavior.
- Bounded event dedupe without whole-map hot-path scans.
- Validated immutable configuration generations with explicit restart-required settings.
- Additive Core API 2.1 contract.

## Migration

PlexonCore 2.1.0 is an in-place upgrade from the 2.0.5 stable line. Existing persisted data is retained and migrated through the supported schema path. Future or unsupported schema versions fail closed rather than being silently rewritten.

Back up the server before upgrading. Do not hot-swap the plugin; stop the server, replace the Core JAR, then start normally.

## Rollback

The known-good rollback baseline is PlexonCore 2.0.5.

If rollback is required after deployment, stop the server before replacing the JAR. Preserve a backup of the PlexonCore data directory taken before the 2.1.0 upgrade.

## Verification

The stable release is published only after:

- the complete PlexonCore build/test/distribution gate passes for version 2.1.0;
- the complete 14-plugin downstream compatibility gate passes against the final 2.1.0 artifact;
- the stable branch commit is identical to the verified main commit;
- the release workflow rebuilds and verifies the final JAR and checksum before publication.

A dedicated runtime certification checklist remains in the repository for deployment verification on the live PlexonCraft host.

The GitHub Release includes the final JAR and SHA-256 checksum file.
