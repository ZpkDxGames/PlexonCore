# PlexonCore 2.0.5

PlexonCore 2.0.5 is the stable closure of the accepted Phase 3 runtime work, with a focused repository-wide reliability pass before production publication.

## Fixed

- Updated the Core integration registry to track `PlexonGPFlags`, the active replacement for deprecated `PlexonClaimFlags`.
- Isolated shared `PlayerWatchService` subscribers so one module callback failure cannot block other subscribers or terminal watch cleanup.
- Corrected scheduler delay conversion so non-50 ms durations are rounded up instead of being scheduled earlier than requested.
- Made compiled block subscription routes safely visible across threads without adding synchronization to the event hot path.

## Release hardening

- Added regression coverage for player-watch failure isolation, scheduler delay rounding, and the active GPFlags integration identity.
- Consolidated publishing around the generic stable release workflow.
- Strengthened CI/release checks for Java 25 bytecode, Paper 26.2, embedded plugin version, SQLite shading, and server-API isolation.

## Compatibility

- PlexonCore API remains `2.0` with the API `1.0` compatibility bridge intact.
- Target runtime remains Paper `26.2` on Java `25`.
