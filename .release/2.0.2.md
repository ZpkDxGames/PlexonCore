# PlexonCore 2.0.2

PlexonCore 2.0.2 builds on 2.0.1's safe provenance-import API and corrects the final block outcome contract required by Core-backed gameplay modules.

## Fixed

- Capture event-time block origin before Core provenance cleanup.
- Dispatch block subscribers at the final `MONITOR` stage instead of the earlier `HIGHEST` stage.
- Suppress callbacks when a `BlockBreakEvent` is finally cancelled.
- Expose the final `dropItems` value in `CoreBlockBreakContext`.
- Retain the original Core 2.0.0 context constructor signature for existing compiled consumers.

## Preserved from 2.0.1

- Idempotent player-placed provenance import APIs and migration markers.
- Fail-closed `UNKNOWN` origin semantics.
- Version-derived build/release artifact naming.

- Paper 26.2
- Java 25
