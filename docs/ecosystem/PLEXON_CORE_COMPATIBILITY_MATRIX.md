## Matrix rules

- An active changed plugin is listed as published only after exact source/release target, JAR and SHA-256 were verified.
- `CERTIFIED_WITH_RUNTIME_PENDING` means source, CI and GitHub release provenance are closed while live server gates remain unexecuted.
- `PRERELEASE_NOT_CERTIFIED`, `PRERELEASE`, `PLANNED_NOT_ACTIVE` and `DEPRECATED` artifacts are excluded from the production deployment lock.
- No `UNMANAGED_BINARY` remains in the audited named repository set.
